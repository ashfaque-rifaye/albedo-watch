# Albedo-Watch — submission text

**Track:** 02 — Clean Air & Climate Resilience

## Brief description (2–3 lines)

Albedo-Watch is a citizen-powered air-intelligence network for India: anyone can report smoke by photo or voice note in their own language, and Gemini 3.7 Flash verifies it against NASA satellite fires and routes it to the responsible authority. It traces each city's pollution back to its sources, forecasts air-quality spikes 72 hours ahead for 53 cities in 26 states, and drafts GRAP-aligned action orders with voice advisories in local languages, with a human approving every dispatch. States improve each other's forecasts through a federated Model Commons that shares only model weights, cutting forecast error by about a third, even for states that contribute no data.
